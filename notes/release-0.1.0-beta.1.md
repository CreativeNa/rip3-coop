# RIP 3: The Last Hero — Co-op 0.1.0-beta.1

Первый публичный бета-релиз мода: сетевой кооператив, русский язык, FSR-экран и быстрая загрузка. Файлы игры не изменяются.

## Установка

1. Нужна RIP 3: The Last Hero из Steam.
2. Распакуйте архив в любую папку.
3. Запустите **«Запустить игру с модом.cmd»**.
4. Игра должна быть закрыта; Steam должен быть запущен.

В главном меню появятся **«КООПЕРАТИВ»** и кнопка **«Язык: RU/EN»**.

## Что умеет

- Кооп по коду приглашения: прямое UDP-соединение, без сервера.
- Lockstep: обе игры считают одно и то же, по сети идёт только ввод.
- Общие меню, выбор героя, пауза Esc с любой стороны.
- Выравнивание состояния на каждой загрузке уровня.
- Сохранение прогресса друга профилем «КООП <имя>».
- Режим **Radmin VPN** для строгого NAT.
- Ожидание до 30 секунд при коротком обрыве и приём нового адреса NAT.
- Русский и английский язык игры, FSR-апскейл, borderless-окно, быстрая загрузка.
- Защита окна от сброса после Win+D/смены разрешения.

## Известные проблемы

- **Кооп не проверен на двух реальных ПК.** Это главный риск релиза.
- Кнопка «Язык: RU/EN» может не реагировать. Обход: вручную изменить `Language` в `build\rip3mod.ini` и перезапустить игру.
- Автозапуска после смены языка нет: игру нужно запустить вручную, когда Steam отпустит процесс.
- Нет ретранслятора при строгом NAT, кроме Radmin VPN.
- Нет восстановления рассинхрона посреди уровня — только на загрузке.
- Геймпад и строка состояния проверены не в живой сессии.
