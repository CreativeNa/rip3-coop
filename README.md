# RIP 3: The Last Hero — кооп по сети, русский язык, современный экран

Мод для **RIP 3: The Last Hero** (Steam, RIP — Trilogy, appid 2550). Файлы игры не меняются: мод подгружается в процесс игры при запуске.

## Возможности

### Сетевой кооператив
- Игра вдвоём через интернет по **коду приглашения** из 9 символов. Сервер не нужен: прямое UDP-соединение, адрес определяется через STUN.
- **Режим Radmin VPN** в том же экране: код содержит адрес `26.x.x.x`, пакеты идут через виртуальную сеть. Обходит строгий NAT/CGNAT; режим должны включить оба игрока.
- **Короткий обрыв связи**: игра ждёт друга до 30 секунд и продолжается сама; если у друга сменился адрес NAT, лаунчер переходит на новый адрес по HELLO.
- Модель **lockstep**: обе игры считают одно и то же, по сети ходит только ввод. Генератор случайных чисел общий, расхождения проверяются каждый кадр.
- **Экран кооператива** открывается кнопкой «СЕТЕВАЯ ИГРА» в главном меню или по F7. Он оформлен в стиле игры.
- Друг сам выбирает героя и имя: меню, курсор и пауза общие.
- Пауза — Esc у любого из игроков. На экране видно, кто её поставил.
- На каждой загрузке уровня игры **сверяются и выравниваются**.
- **Прогресс друга** при выходе сохраняется в его `save.dat` профилем «КООП <имя>».
- **Строка состояния**: пинг, задержка ввода и доля времени, которую игра ждала друга. Цвет показывает качество связи.
- **Геймпад XInput** для второго игрока: ходьба, поворот правым стиком, огонь, оружие.
- **Тест с ботом**: ИИ играет за второго игрока — стреляет, уворачивается, переключает оружие.

### Русский язык
- Перевод текста меню, уровней, оружия и перков.
- Русские надписи на картинках меню. Картинки создаются скриптом из файлов игры.

### Экран и звук
- Окно без рамки на весь монитор, без смены разрешения.
- Увеличение картинки в стиле **FSR 1**: Catmull-Rom и резкость RCAS. Ещё два режима: чёткие пиксели и обычное сглаживание.
- Ограничение частоты кадров, пропуск заставок, снимок экрана по F12.
- Нет вылетов, если не подключены наушники или колонки.
- **Загрузка до меню вдвое быстрее**: 6,5 → 3,2 с. Для файлов архива строится индекс, распаковка PNG ускорена.

## Установка и запуск

Нужна RIP 3 из Steam. Готовую сборку (`dist/rip3-coop.zip`) можно распаковать в любую папку. Запуск — двойным щелчком по **«Запустить игру с модом.cmd»** (технический вариант — `start_rip3.cmd`).

Окно запуска показывает этапы: проверка файлов, запуск Steam, проверка версии `RIP3.exe`, подключение мода. При ошибке оно остаётся открытым и объясняет причину; подробности пишутся в `build/launch.log`. Перед запуском игра должна быть закрыта.

Пошаговая инструкция по игре вдвоём — в [dist/README_RU.txt](dist/README_RU.txt).

### Управление второго игрока

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Ходьба | W A S D | левый стик / крестовина |
| Поворот | H / K | правый стик, LB / RB |
| Огонь | J | RT или A |
| Доп. огонь | U | LT или B |
| Оружие 1 / 2 / 3 | 1 / 2 / 3 | X / Y / Back |
| Пауза | Esc | Start |

### Настройки (`build/rip3video.ini`)

| Параметр | Значения |
|---|---|
| `Mode` | `borderless` — во весь экран без рамки, `window` — окно |
| `Upscale` | `fsr`, `sharp`, `bilinear` |
| `Scale` | `stretch` — на весь экран, `fit` — 4:3 с полосами, `integer` — целое увеличение |
| `FpsLimit` | `60`, или `0` — без ограничения |
| `SkipLogos` | `1` — пропустить заставки |
| `FastLoad` | `1` — ускоренная загрузка |
| `Profile` | `1` — записать в лог, на что уходит время загрузки |

## Сборка

Нужен [Zig](https://ziglang.org) 0.17 в `tools/zig/`: он собирает 32-битные DLL для Windows через `zig cc`.

```
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

Результат появляется в `build/`. Картинки с русскими надписями собираются из копии игры в `game/data.pak`, её нужно положить туда самому.

Готовый архив для раздачи:

```
powershell -ExecutionPolicy Bypass -File scripts\package.ps1
```

Он пересобирает всё, кладёт только файлы для игрока (без логов, PDB и кешей) в `dist/rip3-coop.zip` и добавляет `SHA256SUMS.txt` и `VERSION.txt`.

| Файл | Что делает |
|---|---|
| `src/rip3net.c` → `rip3net.dll` | сетевой кооп: lockstep, общий ввод, экран кооператива, ИИ, геймпад |
| `src/rip3coop.c` → `rip3coop.exe` | связь: UDP, STUN, коды приглашения, боты для тестов |
| `src/rip3video.c` → `rip3video.dll` | экран, FSR, звук без устройства, ускорение загрузки, профилировщик |
| `src/rip3ru.c` → `rip3ru.dll` | русский текст |
| `src/inject.c` → `inject.exe` | подгружает DLL в игру по PID |
| `start_rip3.ps1` | запускает игру через Steam, проверяет версию exe и инжектит мод |
| `src/netproto.h` | формат сетевых пакетов |
| `src/rip3hook.c` | запись и повтор ввода для проверки детерминизма |
| `scripts/ghidra/` | скрипты Ghidra для исследования игры |
| `scripts/img/` | перевод надписей на картинках |
| `notes/` | заметки об устройстве игры и о каждом этапе |
